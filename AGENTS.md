# Работа с релизами

- Перед каждой релизной сборкой Android или веб-приложения закоммитьте все изменения, которые должны войти в релиз, включая обновление версии, если оно требуется, и запушьте коммит в GitHub. Запускайте сборку только после успешного `git push`. Если исходники изменились перед повторной сборкой, сначала закоммитьте и запушьте эти изменения.
