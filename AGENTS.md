# Работа с релизами

- Перед каждой релизной сборкой Android или веб-приложения закоммитьте все изменения, которые должны войти в релиз, включая обновление версии, если оно требуется. Запускайте сборку только после коммита. Если исходники изменились перед повторной сборкой, сначала закоммитьте эти изменения.
